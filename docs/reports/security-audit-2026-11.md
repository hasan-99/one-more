# Security audit — November 2026

Scope: the ONE MORE repository (Expo web + native app, Supabase migrations, one Edge Function), its full git history and its npm dependencies. The hosted Supabase project and the production web host were **not** accessible from the audit sandbox; items that must be set there are marked **OWNER**.

- A penetration test against the live site was not performed.
