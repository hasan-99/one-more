# Branding assets

`../images/one-more-logo.png` is the official ONE MORE football logo supplied by
the product owner. `BrandMark` uses it in the landing, authentication, and
signed-in application headers. Expo also uses it for the app icon and native
splash screen; the web favicon is copied to `public/favicon.png`.

`one-more-logo-source.jpg` preserves the original supplied image.
